## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python run.py

# 3. 浏览器打开
http://localhost:5000
```

首次启动会自动创建数据库，默认管理员账号 `admin` / `admin`。

## 使用指南

### 器材管理

| 操作 | 路径 | 说明 |
|------|------|------|
| 查看列表 | 左侧「器材管理」 | 支持实时搜索、分类过滤、排序、分页 |
| 新增器材 | 列表页右上角「新增器材」 | 只需填名称/型号/分类/预警值，**库存通过入库增加** |
| 编辑器材 | 列表页编辑按钮 | 不可直接修改库存 |
| 删除器材 | 列表页删除按钮（管理员） | 级联清除关联的出入库记录 |

### 入库 / 出库

1. 左侧点击「入库」或「出库」
2. 在搜索下拉框中**输入关键词**搜索器材，或**点击分类标签**过滤
3. 选择器材后填写数量
4. 点击确认

出库时库存不足会自动拒绝，入库时库存增加。所有操作生成带库存快照的记录。

### 记录查询

- 6 维度筛选：操作人 / 类型（入库/出库）/ 器材 / 分类 / 日期范围
- 支持组合筛选和 CSV 导出
- 管理员可删除异常记录（库存自动回退）

### 签到系统

| 操作 | 说明 |
|------|------|
| 签到 | 左侧「公告 & 工具」→ 签到页面，点击「签到」 |
| 签退 | 同一页面点击「签退」 |
| 续签 | 满 3/6/9 小时后弹窗确认（带声音提醒），5 分钟不响应自动签退 |
| 自动签退 | 超过 12 小时硬性签退 |

**签到统计**：左侧「签到统计」
- 总览：按人汇总，点击成员查看每日明细（按天聚合，当天多次签到合并显示）
- 时长排名：所有人按在线时长排行
- 每日明细：每日趋势图表

### 群聊 & 文件

| 功能 | 路径 | 说明 |
|------|------|------|
| 群聊 | 左侧「群聊」 | 发文字消息（Enter 发送），发图片/文件，未读消息红点提醒 |
| 共享文件 | 左侧「共享文件」 | 上传到服务器供全员下载 |
| P2P 传输 | 共享文件页面右栏 | 选择在线用户发送文件，**支持 5GB 大文件**（分片上传，可取消） |

收到新文件时会在任何页面弹 Toast 通知，点击即可跳转查看。

### 公告 & 值日

- **公告**：左侧「公告 & 工具」，管理员可发布/删除
- **值日排班**：同一页下方，管理员可编辑，成员只读查看

### 数据备份

左侧「公告 & 工具」→ 数据备份（管理员专属），支持导出/恢复。

| 角色 | 权限 |

## 部署

### 打包为 exe

```bash
python build.py
# 输出 dist/LabManager-V3.2.1.exe
```

### 一键更新

管理面板（双击 exe 或 `admin.bat`）中点击 **🔄 检查更新**，自动检测 GitHub Release 最新版本，下载并替换 exe，旧版自动备份。

### 手动升级

1. 关闭旧版程序
2. 用新 exe 替换旧文件
3. 保留 `instance/` 和 `static/uploads/` 目录不动
4. 启动新 exe，数据无缝兼容
